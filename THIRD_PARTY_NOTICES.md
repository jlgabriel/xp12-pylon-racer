# Third-party notices

## Pylon models

None. The pylons XP Pylon Racer installs are generated by the app itself (`src/core/pylon/`): a
tapered tube written as an X-Plane OBJ8 object and a banded PNG texture, made on your computer when
you install a course. No model or texture from Laminar Research, IPACS or any other artist is
shipped or copied.

## Code from the author's other projects (GPL-3.0-or-later)

- From **Pylon Racer** (Aerofly FS 4, https://github.com/jlgabriel/afs4-pylon-racer): the race
  engine, the course model and file format, runs, rankings and the user interface.
- From **XP Object Placer** (https://github.com/jlgabriel/xp12-object-placer): the binary DSF writer,
  the scenery_packs.ini editor and the X-Plane installation finder.

Both are by the same author and under the same license as this app.
